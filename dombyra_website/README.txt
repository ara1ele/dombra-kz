DOMBYRA — учебный сайт

Как запустить:
1. Скачайте и распакуйте архив.
2. Откройте папку dombyra_website.
3. Дважды нажмите index.html — сайт откроется в браузере.

В проекте:
- index.html — структура, оформление и JavaScript в одном файле.
- Переключение языка KZ / RU / EN уже работает.
- Для Google Fonts и фотографий требуется подключение к интернету.

Важно:
Фотографии сейчас подгружаются с Unsplash как временные изображения для макета.
Перед сдачей проекта проверьте источники изображений и замените их при необходимости.
Исторические тексты — краткое введение; для академической версии добавьте отдельный список источников.
